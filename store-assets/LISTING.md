# Chrome Web Store 上架文案

## 名称（最多 45 字符）

```
Starmap 星图 — GitHub 星标管理
```

## 简短说明（最多 132 字符）

```
把 GitHub 星标变成可检索的地图：自动归类、模糊查找、记号记、清理死仓库。无服务器，数据只在你自己手里。
```

字符数：约 55（中文字符按 2 计约 110）

---

## 详细说明

```
你 star 了几百上千个仓库，然后呢？

需要用的时候，只记得"那个做动画的 JS 库"，却想不起叫什么。
或者压根不记得自己还 star 过它。

Starmap（星图）解决的就是这件事。


■ 自动归类，不用手动打标签

借 GitHub 自带的 topic、语言、作者、收藏时间，自动把你的 star 分成五个视角：
· 按主题   —— "那个动画库"
· 按语言   —— "那个 Rust 的"
· 按作者   —— "那个作者的作品集"
· 按年份   —— "去年收藏的"
· 按我的标签 —— 你自己整理的

不用维护分类体系，仓库自己会归位。


■ 找得回来

· 模糊搜索：名字、描述、topic、你自己的标签和备注，全都搜得到
· 交叉过滤：点「react」再点「动画」，只留同时满足的
· 多维度排序：收藏时间、star 数、最后更新、名称


■ 记住你为什么 star 它

· 给任意仓库写一句话备注 —— "当初是为了找短剧素材收藏的"
· 打自己的标签，和 GitHub 的 topic 分开
· 这些内容会自动同步到你自己的 GitHub Gist，换设备也在


■ 直接在 GitHub 页面上用

打开你的星标页，会多出：
· 顶部工具条：搜你的备注、按标签筛选
· 每个仓库下方显示你写的标签和备注
· 点「编辑」原地修改，不用跳来跳去

三项都可以在设置里单独关掉。


■ 清理积压的 star

自动找出可能不再需要的：
· 已归档的仓库
· 镜像仓库（原仓库已经在 GitHub 上了）
· Fork 的仓库
· 长期不更新的
· 收藏后再没标注过的

按类别分组勾选，你标注过备注或标签的仓库绝不会出现在列表里。
所有取消操作都要你手动确认，不会自动删除任何东西。


■ 关于隐私

· 没有服务器、没有数据库、没有任何自建服务
· 所有请求直接发往 api.github.com
· 你的 Token 只存在本机浏览器，不上传
· 笔记和标签存在本地 + 你自己的 GitHub Gist
· 无统计、无追踪、无第三方 SDK

完整隐私政策见下方链接。


■ 开始使用

1. 安装扩展
2. 点工具栏图标打开工作台
3. 按引导创建一个 GitHub Token（会告诉你要勾哪些权限，链接直达创建页）
4. 粘贴，完成

Token 只需要 read:user 和 gist 两个权限。
想用清理功能的话再勾 public_repo。


■ 反馈与支持

遇到问题或有任何改进建议，欢迎通过邮件联系开发者：
sneaker@agent.qq.com


■ 说明

· 需要 GitHub 账号
· 仅支持 Chrome（Firefox / Edge 版本尚未适配）
· 开源，代码可在 GitHub 查看
```

## 权限说明（上架时需填写）

Chrome 商店上架时，每个权限都要填写理由：

| 权限 | 用途说明 |
|---|---|
| `storage` | 在本地保存你的 Token、备注、标签和 star 数据缓存 |
| `https://api.github.com/*` | 读取你的 star 列表、取消 star、访问你的 Gist 做跨设备同步 |
| `https://github.com/*` | 在你的 GitHub 星标页显示工具条和注解，让你原地编辑备注 |

---

## 数据使用声明（Chrome 商店表单）

上架时需勾选数据收集类型。本扩展的答案是：

| 问题 | 回答 |
|---|---|
| 是否收集个人身份信息 | 否 |
| 是否收集健康信息 | 否 |
| 是否收集财务信息 | 否 |
| 是否收集认证信息 | **是**（GitHub Token，仅本机存储，不上传） |
| 是否收集个人通信 | 否 |
| 是否收集位置 | 否 |
| 是否收集网页浏览活动 | 否 |
| 是否收集用户活动 | 否 |
| 是否收集网站内容 | **是**（读取你的 star 列表，用于展示） |

**数据传输承诺**（三项都要勾"不"）：
- 不出售给第三方
- 不用于与核心功能无关的用途
- 不用于判断信用度或放贷
