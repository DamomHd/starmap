Privacy Policy

Last updated: October 27, 2026

Zero servers. Your data stays strictly in your browser and GitHub account.

This extension collects, uploads, and shares nothing with any third party.

Starmap ("this extension") is a browser extension that helps manage GitHub starred repositories. This policy describes what data this extension handles, how it is used, and data sharing guarantees.

1. What Information Is Handled

All data is processed strictly on your local device.

1.1 Information you provide

DataPurposeStorage Location
GitHub Personal Access Token (PAT) Calling GitHub API to read stars and sync to Gist Local browser storage (chrome.storage.local)
Your notes and tags Helping you recall why you starred a repository Local browser storage; if sync is enabled, saved to your personal Secret Gist

1.2 Public information from GitHub

DataSourcePurpose
Starred repository list (names, descriptions, languages, topics, star counts) GitHub Official API Display, search, and multidimensional clustering
GitHub username GitHub Official API Displaying current account identity in UI

This data is cached locally in your browser for 30 minutes and is never transmitted to any third party.

1.3 What we never collect

  • ❌ No browsing history
  • ❌ No web page content outside GitHub
  • ❌ No device identifiers, IP addresses, or location data
  • ❌ No telemetry, click tracking, or analytics
  • ❌ No cookies or third-party SDKs

2. How Data Is Used

All data is used exclusively to deliver the core functionality of this extension:

  • Fetching stars → Display, filter, and cluster starred repositories
  • Reading username → Show connected identity in the topbar
  • Notes & tags → Save your private annotations for instant search
  • PAT token → Authenticate official requests to GitHub API on your behalf

No other use cases exist. Not used for user profiling, advertising, machine learning model training, or commercial reuse.

3. Third-Party Sharing

Zero sharing. Network requests are strictly limited to:

DomainPurpose
api.github.comReading starred repositories and unstarring
github.comAccessing your personal Secret Gist for cross-device sync

4. Data Retention & Control

Locationchrome.storage.local (Local browser storage, extension sandbox isolated)
RetentionRetained until you delete entries or uninstall the extension
CacheStar repository cache expires automatically after 30 minutes

5. Security

Browser extension code can be unpacked and inspected by design. Therefore, Starmap does not rely on code secrecy to protect your data:

  • Zero hardcoded API secrets or master keys
  • Your token resides exclusively in your local browser sandbox
  • No central server, eliminating central data breach risks
