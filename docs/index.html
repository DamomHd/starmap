隐私政策

最后更新：2026-10-27

没有服务器。你的数据只存在你自己的浏览器和你的 GitHub 账号里。

本扩展不收集、不上传、不共享任何东西。

Starmap（星图）是一个管理 GitHub 星标的浏览器扩展。本文说明本扩展处理哪些数据、如何使用、以及是否存在共享。

1. 处理哪些信息

所有信息都只在你的设备本地处理。

1.1 你主动提供的

数据用途存储位置
GitHub 个人访问令牌（PAT） 调用 GitHub API 读取你的星标、写入 Gist 你的浏览器本地（chrome.storage.local）
你写的备注、标签 帮你记住"为什么 star 它" 浏览器本地；开启同步时，另存于你自己账号下的 Secret Gist

1.2 从 GitHub 获取的公开信息

数据来源用途
你的星标仓库列表（名称、描述、语言、topic、star 数等）GitHub API展示与分类
你的 GitHub 用户名GitHub API显示当前登录账号

这些数据缓存在浏览器本地，30 分钟后自动失效，不会发送到任何第三方。

1.3 我们不收集的

  • ✕ 浏览历史
  • ✕ 你在 GitHub 之外的任何网页内容
  • ✕ 设备信息、IP 地址、地理位置
  • ✕ 使用统计、点击行为、崩溃报告
  • ✕ Cookie，也不接入任何分析或广告 SDK

2. 如何使用这些信息

所有数据仅用于本扩展的核心功能：

  • 读取星标 → 展示、分类、搜索你的星标仓库
  • 读取用户名 → 在界面上显示当前登录账号
  • 备注与标签 → 保存你对仓库的私人记录，用于检索和显示
  • PAT → 作为身份凭证，代表你调用 GitHub 官方 API

不存在其他用途。不用于画像、广告、训练模型或任何形式的二次利用。

3. 是否与第三方共享

不共享。本扩展的所有网络请求只发往以下两个域名：

域名用途
api.github.com读取星标、取消 star
github.com访问你自己的 Gist（跨设备同步时）

除此之外没有任何后端、代理、CDN 或统计服务。

关于跨设备同步（可选功能）

若你开启"自动同步"，你的备注和标签会写入你自己 GitHub 账号下的一个 Secret Gist。

  • 该 Gist 由你自己拥有和控制
  • 只有持有链接的人能访问（GitHub 的 Secret Gist 机制）
  • 你可以随时在 GitHub 上删除它
  • 不开启同步时，数据完全不离开你的浏览器

关于 GitHub 自身

你的请求经过 GitHub 的服务器——这和使用 GitHub 网站本身没有区别。GitHub 如何处理数据见 GitHub 隐私声明。

4. 数据存储与保留

位置chrome.storage.local（浏览器本地存储），只有本扩展可访问
保留时间直到你删除，或卸载扩展
缓存星标数据缓存 30 分钟后自动失效

你的控制权

你想做什么怎么做
删除某条备注/标签在界面上清空该仓库的备注和标签
删除所有本地数据卸载扩展，或在设置里移除 Token
撤销本扩展的访问权限GitHub → Settings → Applications → 撤销该 Token
删除云端同步数据到 GitHub 删除对应的 Secret Gist

撤销 Token 后，本扩展立刻失去所有能力。

5. 关于代码可见性

浏览器扩展的代码是可以被查看的——任何人下载扩展后都能解压看到源码。这是 Chrome 平台的特性，所有扩展都如此。

因此本扩展在设计上不依赖代码保密来保护你的数据：

  • 没有任何硬编码的密钥或凭证
  • 你的 Token 只存在你自己的浏览器里
  • 没有服务器，所以不存在"服务器数据泄露"
  • 即使源码完全公开，攻击者也拿不到其他用户的数据

6. 儿童隐私

本扩展不面向 13 岁以下儿童，也不会有意收集儿童信息。

7. 政策变更

若本政策发生实质变更，会在扩展的更新说明中告知。

对未来的承诺

如果未来本扩展引入任何服务器或第三方服务，会在此文档中明确说明，并在扩展界面同步更新——不会偷偷改变。

8. 联系的渠道

如对隐私处理有疑问、发现安全问题或有软件开发反馈，请通过项目仓库的 Issues 反馈，或直接发送邮件至 sneaker@agent.qq.com。

附：权限说明

权限为什么需要
storage在本地保存 Token、备注、标签和缓存
api.github.com读取你的星标、取消 star
github.com在星标页显示工具条；同步时访问 Gist
